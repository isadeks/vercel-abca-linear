# vercel-abca-linear

A travel guide site with a Vercel serverless booking API.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or later
- [Vercel CLI](https://vercel.com/docs/cli) (optional, for local development with serverless functions)

### Install

```bash
npm install
```

### Run locally

To serve the static site and API together, use the Vercel CLI:

```bash
npx vercel dev
```

Alternatively, open `index.html` directly in your browser to browse the static pages without the API.

### Lint

```bash
npm run lint
```

### Test

```bash
npm test
```
