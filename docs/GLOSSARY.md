# Glossary

- **Destination Guide**: A dedicated HTML page describing a travel location, such as `kyoto-guide.html` or `amalfi-guide.html`.
- **Quiz**: The interactive feature (`quiz.html`) that recommends destinations based on a visitor's answers.
- **API**: Serverless functions under the `api/` directory that provide backend endpoints for the site.
- **Channel**: A distribution or marketing pathway through which travelers discover and book destinations, such as social media, email, or partner websites.
